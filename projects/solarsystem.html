🪐 3D Solar System

A small OpenGL project where I went from rendering a single triangle to building an animated and textured solar system — creating the geometry, lighting, shaders and planetary motion along the way.

Individual project — Télécom Paris

  • OpenGL
  • C++
  • GLSL
  • Phong Lighting
  • Shaders
  • Textures
  • 3D Graphics

01 — Geometry

From a triangle to a sphere.

Rather than using an existing sphere model, I generated the sphere mesh procedurally.

I divided the sphere into horizontal and vertical segments and computed each vertex position from spherical coordinates. From this I generated the vertex positions, normals, texture coordinates and triangle indices.

The resulting geometry was then uploaded to OpenGL using VBOs, an index buffer and a VAO before being rendered with glDrawElements().

02 — Lighting

Giving the sphere depth.

Once the geometry worked, I implemented Phong lighting in the fragment shader.

For every fragment, the final illumination combines ambient, diffuse and specular components. The Sun is treated differently as a light-emitting object, while the planets receive illumination from it.

03 — Shaders & Textures

Turning spheres into planets.

The same sphere geometry could then be reused for every planet. What changes are its transformation matrix and texture.

The vertex shader transforms each vertex using the model, view and projection matrices and passes the transformed normals and texture coordinates to the fragment shader.

The fragment shader samples the planet texture and combines it with the Phong illumination to produce the final pixel color.

04 — Animation

Making the system move.

Each planet uses its own transformation matrix composed from translation, rotation, axial tilt and scaling.

Every frame, I use the elapsed time to update the rotation angles. By combining transformations, a planet can rotate around its own axis while simultaneously orbiting the Sun.

Once this logic worked for the first celestial bodies, I reused the same system to add the remaining planets.
