AI & Computer Vision — 4IM06 Project, Télécom Paris

🎨 Can AI classify abstract and figurative art?

My contribution to a team project on abstract vs. figurative art classification was to explore the problem from an interpretable computer-vision perspective: instead of asking a neural network to learn its own representation, I designed visual measurements for color, texture, edges, brushstrokes, composition and frequency — and tested how far they could go.

Team project with Marie-José Tannoury, Charbel Abou Kheir & Sergio Sanchez — supervised by Henri Maître & Loïc Le Folgoc.

31 features designed
6 visual feature families
15 features in the best subset
81.4% balanced accuracy

The question

Can we describe abstraction with measurable visual properties?

The team explored four different ways of solving the problem. My part was the hand-crafted feature approach. I wanted to see whether properties that humans can understand and describe — color diversity, texture complexity, edge structure, brushstroke direction or frequency content — could be converted into numerical features and used to distinguish the two categories.

My approach

Turning paintings into 31 interpretable numbers.

Instead of feeding the raw image directly to a deep neural network, I built a feature-extraction pipeline that transforms every painting into a vector of 31 hand-crafted visual features.

Feature family What I wanted to capture Examples
Color How varied, saturated and perceptually diverse the palette is. Saturation, brightness, hue entropy, dominant colors, Lab color spread
Edges Whether the image contains coherent object boundaries or more chaotic edge structures. Canny density, orientation entropy, contour length, curvature
Texture The complexity and regularity of local surface patterns. LBP entropy, GLCM contrast, homogeneity, energy, correlation
Brushstrokes Whether strokes have strong directions and how much their widths vary. Stroke anisotropy, stroke width variance
Composition How visual information is distributed across the painting. Symmetry, quadrant balance, edge-frame ratio
Frequency The amount and distribution of fine versus coarse visual detail. FFT frequency ratio, entropy, radial falloff

Classification

From visual measurements to a decision boundary.

Once every painting had been converted into a feature vector, I standardized the features and compared several classical machine learning classifiers.

Model Balanced accuracy
Random Forest ≈ 0.66
KNN ≈ 0.66
Gradient Boosting ≈ 0.71
Logistic Regression ≈ 0.77
SVM — RBF kernel ≈ 0.80

The RBF SVM performed best. Unlike a linear classifier, the RBF kernel can model non-linear interactions between the visual descriptors — useful here because no single property defines whether a painting is abstract.

I then tuned the SVM using a grid search over C and γ. The strongest region was around C = 1 and γ = 0.1.

Feature selection

More features did not mean a better model.

One of the most interesting parts of my experiments was testing whether all 31 features were actually useful.

I ranked the features using Random Forest importance, then progressively removed the least important features and re-evaluated the SVM. The experiment went from all 31 features down to a single feature.

Surprisingly, performance did not decrease immediately. The best result was obtained with only 15 features, reaching approximately 0.814 balanced accuracy.

The 15 features that survived

Family Selected features
Color mean saturation, saturation std., mean brightness, hue entropy, saturation entropy
Edges orientation entropy, contour mean length, contour curvature
Texture LBP entropy, GLCM contrast, homogeneity, correlation
Strokes stroke anisotropy, stroke width variance
Frequency radial falloff

Color and texture descriptors were particularly well represented in the final subset. Interestingly, the composition features disappeared entirely.
